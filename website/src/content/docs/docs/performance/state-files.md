---
title: Save and Load State Files
description: Save and restore complete plugin state as .tanghim files.
---

Tanghīm can save and load its complete state as `.tanghim` files — human-readable JSON that captures your tuning system, maqam, slider positions, presets, and reference frequency.

- **Save**: File → Save (or use the menu command) to export a `.tanghim` file.
- **Load**: File → Load to restore a saved state.

This is useful for sharing tuning configurations or backing up your setup outside of DAW project files.

Presets are also stored independently in `~/Library/Tanghim/settings.json` (macOS) and shared across all DAWs — a `.tanghim` file lets you manage named snapshots and share them with others.
