Tanghīm is an open-source VST3, AU, and CLAP plugin that accesses Arabic maqām tuning data from [DiArMaqAr](https://diarmaqar.net) and applies it to your instruments. Three tuning methods (**MTS-ESP**, **MPE**, and **Mono Pitch Bend**) ensure compatibility with virtually any synthesizer.
