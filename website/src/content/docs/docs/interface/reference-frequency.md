---
title: Reference Frequency
description: Adjusting the reference pitch of the tuning system.
---

The reference frequency control adjusts the frequency of the tuning system's first pitch, for example yegāh = 98 Hz or ʿushayrān = 110 Hz.

## Controls

- **Arc knob**: drag to adjust (±700 cents range).
- **Hz input**: type an exact frequency; use up/down arrow keys for ±1 Hz nudges.
- **Cents display**: shows the current offset in cents.
- **Semitone buttons** (±): shift by 100 cents.
- **Transposition indicator**: shows the IPN shift (e.g. "C ↗ C#" or "G ↘ F#−").

## Persistence

The reference frequency persists relatively when switching tuning systems or starting note names. For example, if you select a tuning system with starting note name yegāh = 98 Hz and change it to 100 Hz, then switch to ʿushayrān, the plugin will use 112.25 Hz rather than reverting to the default of 110 Hz.
