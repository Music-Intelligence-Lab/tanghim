## Session 37: Mono PB Note Stack (Legato Recall)

### Problem

In mono pitch bend mode, holding note A then pressing note B would cut A. When B was released, silence — A was gone. The user wanted A to continue sounding after B is released (classic mono synth legato behavior).

### Solution: Last-Note Priority Note Stack

Implemented in both C++ Receiver (`MonoPitchBendProcessor`) and M4L js (`mts_midi_effect.js`):

**Data structure:** Array/vector of held notes in press order (last element = sounding note)

**Note On:**
1. Turn off the currently sounding note
2. Remove from stack if re-triggered (prevents duplicates)
3. Push onto stack
4. Send pitch bend + Note On for new note

**Note Off:**
1. Remove from stack
2. If it was the sounding note AND stack is non-empty:
   - Send Note Off for released note
   - Recall previous note from stack top: send PB + Note On (velocity 100)
3. If stack is empty: send Note Off, clear active
4. If it wasn't the sounding note: swallow (already cut)

**Stack cleared on:** `allNotesOff()`, mode switch
